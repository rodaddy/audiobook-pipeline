## Decisions Made

- **Used token_set_ratio over ratio** -- Handles subset matching better ("The Way of Kings" vs "Way of Kings")
- **Franchise folders as known constants** -- Not auto-detected; explicit FRANCHISE_FOLDERS dict
- **Source deduplication** -- Removes duplicate entries when same book appears in multiple source subdirectories
- **NON_AUTHOR_FOLDERS** -- Skip container folders (NewBooks, Audiobooks, etc.) when guessing author from path
- **4-tier matching strategy** -- Exact same-author -> exact cross-author -> fuzzy same-author -> fuzzy any-author

## Learnings

- **token_set_ratio is superior for audiobook titles** -- Handles word order and subset matching naturally, critical for title variations like "The Way of Kings" vs "Way of Kings"
- **Chapter-per-file M4Bs are common** -- Older rips often have 41+ separate chapter files in one directory, must be grouped
- **Author name variations are #1 false negative source** -- Single-letter collapsing regex (`\b[A-Z]\.\s*` -> single char) is essential
- **pbcopy commands, never paste in markdown** -- User's terminal formatting gets corrupted when pasted in markdown blocks
- **Repo as agent source of truth** -- Agent files should live in .claude/agents/ in repo, with symlinks pointing TO the repo (not from repo to ~/.claude)
- **Cherry-pick for clean PR history** -- When feature branch has messy history or diverged from main, create clean branch and cherry-pick relevant commits for PR
